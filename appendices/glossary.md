# Glossary: Metrology & Inspection Terms

## A

**AOI (Automated Optical Inspection):** Machine vision system for detecting defects in manufacturing using light-based imaging.

**APC (Advanced Process Control):** Closed-loop feedback system that automatically adjusts manufacturing parameters based on metrology measurements.

**Aspect Ratio:** Height-to-width ratio of a feature (e.g., trench depth / trench width).

## B

**BSE (Backscattered Electrons):** High-energy electrons scattered backward from sample in SEM; used for contrast imaging.

**Bright-field imaging:** Imaging mode using direct (non-scattered) light reflection.

## C

**CNN (Convolutional Neural Network):** Deep learning architecture used for image classification and defect detection.

**Contrast:** Difference in reflectivity between defect and background; critical for detection.

## D

**Dark-field imaging:** Imaging mode using only scattered light; enhances edge detection.

**Defect density:** Number of defects per unit area; typically defects/cm².

**De Broglie wavelength:** Wavelength associated with moving electrons; λ = h/p.

## E

**E-beam metrology:** Scanning electron microscope (SEM) for nanoscale defect detection.

**EOT (Equivalent Oxide Thickness):** See Book 6 (Deposition); relevant to gate dielectric inspection.

## F

**False negative:** Real defect that was not detected.

**False positive:** Reported defect that is actually not a defect (measurement artifact or noise).

## I

**Installed base:** Number of equipment systems deployed at customer sites.

## L

**Langmuir probe:** Diagnostic tool for plasma characterization (relevant to etch/deposition feedback).

## M

**ML (Machine Learning):** Algorithms that learn patterns from data without explicit programming.

**Morphological filtering:** Image processing technique using opening, closing, and dilation operations.

## N

**NA (Numerical Aperture):** Measure of lens light-gathering ability; higher NA = higher resolution.

**Nanometer (nm):** 10⁻⁹ meters; unit for measuring feature sizes.

## O

**Optical inspection:** Defect detection using visible or UV light.

## P

**Precision:** Of reported defects, what fraction are real (inverse of false positive rate).

**Process window:** Range of process parameters that produce acceptable results.

## R

**Recall:** Of real defects, what fraction are detected (inverse of false negative rate).

**ROIC (Return on Invested Capital):** Operating profit / invested capital; measure of capital efficiency.

## S

**SEM (Scanning Electron Microscope):** Instrument using focused electron beam for nanoscale imaging.

**SPC (Statistical Process Control):** Monitoring process with control charts to detect drift.

**Sputtering yield:** See Book 6 (Deposition); relevant to PVD barrier layer inspection.

## T

**TDDB (Time-Dependent Dielectric Breakdown):** Gradual dielectric failure under electric field; measured by metrology.

**Throughput:** Number of wafers processed per time period.

## V

**Voltage contrast:** Image contrast arising from subsurface potential differences (specific to e-beam metrology).

## W

**Wafer:** Silicon substrate on which semiconductor devices are manufactured.

**Wavelength:** Distance between successive peaks of a wave; λ = c/f.
